## Cookie 是什么？为什么要提交？

Cookie 可以理解为浏览器保存的一段登录状态信息。WildAI 的 Gemini 流程使用它来识别用户当前登录的 Google 账号，并完成订阅升级。

这也意味着 Cookie 不是普通验证码，更不是可以随便发给别人的文本。帮助中心明确提醒，导出的 JSON 属于账号凭证信息，只应提交到当前订单流程，不能发给其他人，也不应保存到公开网盘、聊天群或截图中。

操作时建议注意以下几点：

- 只在自己的电脑上操作；
- 不要把 Cookie JSON 发送给客服个人微信或陌生账号；
- 只通过订单页面要求的输入框提交；
- 操作完成后关闭浏览器插件；
- 不要把包含 Cookie 的截图发布到社交平台；
- 如果导出错误，重新登录 Google 后再导出；
- 不要在公共电脑、网吧或他人设备上完成。

如果你对提交 Cookie 这一步无法接受，建议不要购买这种代开方式，可以改用 Google 官方支持的付款渠道，或者选择不需要登录凭证的产品。
